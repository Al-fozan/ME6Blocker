# ME6Blocker 🚫🎮

برنامج مخصص لحظر سيرفرات روكيت ليج (ME6) | A dedicated tool to block Rocket League (ME6) servers.

---

## 🚀 كيفية التشغيل لأول مرة / How to Run:

1. **صلاحيات المسؤول (Crucial):** يجب تشغيل البرنامج كمسؤول (`Run as Administrator`) لكي يتمكن من إضافة قواعد الحظر إلى جدار حماية ويندوز بنجاح.
2. **تنبيه ويندوز الأزرق (SmartScreen):** عند تشغيل ملف الـ `EXE` لأول مرة، قد يظهر لك تنبيه حماية من ويندوز. اضغط على **More info** ثم **Run anyway** لتشغيله بأمان (البرنامج آمن ومفتوح المصدر بالكامل).
3. **التفعيل:** بمجرد فتح الواجهة، اضغط على الزر الدائري الكبير ليتغير اللون إلى الأخضر (ON) ويتم تفعيل الحظر على النطاقات الثلاثة فوراً وبصمت.
